## ChatGPT Plus 支付失败排查手册

已经在官网试过付款但一直失败的用户，可以按下面四个场景对号入座：

### 场景一：银行卡直接被拒（card declined）

最常见的情况。多数国内发行的 Visa / Mastercard 不支持 OpenAI 的境外线上订阅扣款，或者发卡行直接拦截了这笔交易。

**怎么办：** 先致电发卡行确认是否开通了境外线上支付和订阅类扣款。如果发卡行确认没问题但仍被拒，大概率是 OpenAI 侧风控，换卡意义不大，建议直接换开通路径（App Store 内购或[卡密代充](#chatgpt卡密代充)）。

### 场景二：卡没问题，但反复提示支付失败

卡片本身支持外币，却总在付款页面报错，通常是支付环境被风控识别：账单地址、发卡地区和当前网络地区对不上。

**怎么办：** 核对账单地址是否与发卡地区一致，保持网络环境稳定，不要在付款过程中切换地区。调整一次后再试一次即可，不要连续重试。

### 场景三：扣款成功但 Plus 没生效

银行发来扣款短信，ChatGPT 页面却没有变化。

**怎么办：** 先等 10-30 分钟并刷新页面；仍未生效时，在 ChatGPT 设置里查看订阅状态，并通过 OpenAI 帮助中心提交工单，附上扣款凭证。

### 场景四：多次失败后所有卡都刷不过

短时间内连续失败几次后，账号可能进入支付风控冷却期，这时换什么卡都会被拒。

**怎么办：** 停止尝试，至少间隔 24 小时再试。着急使用的话，直接改走[卡密代充流程](#chatgpt卡密代充)，避开官网支付环节。
